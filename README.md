# Allison Cartazista — Landing Page Oficial

Landing page oficial de divulgação para **Allison Cartazista**, especialista em comunicação visual e arte comercial para comércio em Franca/SP e região.

## 🎨 Serviços
- **Cartazes em Papel Cartão**: Gôndolas, ilhas promocionais, balcões, açougues, paredes e recortes especiais.
- **Pintura Comercial em Vitrines**: Lettering promocional e temático em vitrines de vidro com alta durabilidade e fácil remoção.
- **Faixas em Tecido**: Chamadas aéreas e promocionais para fachadas e interiores.
- **Faixas em Plástico**: 100% impermeáveis para áreas externas e chuva.

## 🚀 Tecnologias
- HTML5 Semântico com Schema.org LocalBusiness JSON-LD (SEO Local para Franca/SP)
- CSS3 Neo-Brutalist / Cartoon responsivo com variáveis customizadas
- JavaScript puro (vanilla) para formulários, filtros, galeria lightbox e contador de visitas
- Hospedagem na Microsoft Azure (Azure Static Web Apps - Plano Free)
